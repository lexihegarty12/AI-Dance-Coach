# AI Dance Coach user test checklist

Use this checklist with 3–5 dancers before treating the feedback as validated.

## Test task

1. Open the lesson review page without additional instructions.
2. Choose either Demi-plié in first or Tendu.
3. Select the camera angle that matches the clip.
4. Upload a 5–60 second clip with one dancer and the full body visible.
5. Read the correction and explain what you would try differently.

## Record for each participant

- Did the upload instructions make sense?
- Did the video process successfully?
- Was the main correction understandable?
- Did the green/red visual cue match the dancer's own judgment?
- Would the dancer try the exercise again using this feedback?
- What felt confusing, slow, or untrustworthy?

## Acceptance target

The first usable version should process most clean clips, give a correction the dancer can repeat in their own words, and clearly explain when the camera setup or pose confidence is not sufficient.
